## Ide konkret

### 1. Baris "Tonggak kampung" di kartu menu (DIPILIH run ini,
   lanjutan Ide 29)
Masalah pemain: antara panel "Kampung menginginkan" (target
berikutnya) dan kabar yang tenggelam, tidak ada rekam "apa yang
sudah dicapai" — pemain yang kembali hanya melihat keadaan
sesaat, bukan kemajuan kumulatif.
Cara kerja: fungsi murni `tonggakKampung` di `sumberdaya.ts`
(populasi + jenis bangunan berdiri + hari game -> daftar
tonggak + yang tercapai + satu berikutnya yang paling dekat),
ditampilkan sebagai SATU baris ringkas di kartu menu di bawah
panel kebutuhan: "🏅 Tonggak: 3 dari 7 — ✓ Api pertama, ✓ Gubuk
pertama · Berikutnya: Lumbung berdiri". Display-only, tanpa
fetch baru (data poll yang sudah ada), tanpa ubah sim, tanpa
hadiah. 7 tonggak dari tangga DESAIN-EKONOMI.md: Api pertama,
Gubuk pertama, Lumbung berdiri, Populasi 10, Bengkel pertama,
Balai berdiri, Paviliun makan berdiri.
Dampak sedang, usaha kecil.

### 2. Kilas "Tonggak baru!" saat tonggak tercapai (TIDAK dibangun
   run ini, backlog)
Masalah: baris tonggak hanya terlihat bila menu dibuka; momen
tercapainya tidak terasa. Cara kerja: bandingkan daftar tercapai
dengan snapshot localStorage kunjungan sebelumnya, tampilkan
satu kilas di kartu menu ("🎉 Baru: Lumbung berdiri!") sampai
menu ditutup. Display-only, tanpa hadiah. Usaha kecil-sedang
(butuh aturan snapshot yang tidak berisik saat pertama kali
dibuka).

### 3. Panel detail tonggak (TIDAK dibangun run ini)
Daftar lengkap 7 tonggak dengan centang + syarat tiap yang
terkunci, dibuka dari baris ringkas. Menunggu bukti baris
ringkas dipakai; jangan bangun panel sebelum barisnya terbukti
dibaca. Usaha kecil.
