Fakta vs opini: fakta dari sumber — ambien berlapis (dasar +
siang/malam + cuaca), crossfade antar lapis, mulai hanya setelah
gestur (AudioContext suspended sebelum itu), kontrol volume/mute
wajib, ambien lebih pelan dari SFX aksi, panjang loop berbeda
supaya pola tidak ketahuan; opini sendiri — di Nusantara
halangan "aset loop berlisensi" dari Ide 15 HILANG bila ambien
dibuat prosedural: `src/lib/audio.ts` SUDAH punya buffer noise
2 detik yang dipakai ulang, loop api + loop sungai, master gain,
dan gate gestur — jadi lapis angin/hujan/malam bisa dibuat dari
noise yang sama tanpa satu file audio pun, tanpa paket awal
membengkak, tanpa melanggar autoplay.

## Ide konkret

### 1. Lapis ambien prosedural angin + hujan + malam (DIPILIH run ini, irisan pertama Ide 15)
Masalah pemain: di luar SFX pendek, kampung itu bisu — malam
terasa sama dengan siang, hujan tidak terdengar, padahal fase dan
cuaca sudah ada di sim (fase "pagi/siang/sore/malam",
`cuacaGame`: cerah/berawan/hujan/petir).
Cara kerja: fungsi murni `lapisanAmbien(fase, cuaca)` -> gain
{angin, hujan, malam} (0..1, dijepit); dua-tiga loop persisten
baru di `audio.ts` yang memakai ulang `noiseBuf` (angin: lowpass
~300 Hz + LFO pelan; hujan: bandpass ~1200 Hz; malam: noise
sangat pelan lowpass ~200 Hz) + crossfade lembut via
`setTargetAtTime` di `updateAudioScene`; `AudioSnapshot`
ditambah `faseWaktu` + `cuaca` dari data poll yang SUDAH ada
(Map3D sudah menerima prop `gameFase`; cuaca dari `cuacaGame`
di page.tsx); ikut toggle Suara + gate gestur yang sudah ada;
tanpa fetch baru, tanpa aset, tanpa ubah sim. Tes offline:
tabel pemetaan fase x cuaca + jepit 0..1 + hujan nol saat cerah
+ malam nol saat siang.
Dampak sedang-tinggi, usaha kecil-sedang.

### 2. Bunyi acak jarang: jangkrik/burung sebagai one-shot terjadwal (TIDAK dibangun run ini, lanjutan)
Masalah: loop saja masih terasa mesin bila didengar lama; sumber
(0 A.D., CRYENGINE) sama-sama menambahkan bunyi acak jarang di
atas loop. Cara kerja: penjadwal ringan di `audio.ts` (tiap
20-60 detik, satu chirp/kicau pendek dari osilator, hanya bila
lapis malam/siang aktif + Suara nyala). Menunggu bukti lapis
dasar ide 1 enak didengar. Dampak sedang, usaha sedang.

### 3. Slider volume terpisah Efek / Ambien (Ide 16 — BELUM, menunggu ide 1)
Masalah: toggle Suara sekarang all-or-nothing. Cara kerja: dua
slider di Pengaturan (Efek, Ambien) + simpan localStorage.
TIDAK dibangun sekarang: slider Ambien tanpa ambien adalah
kontrol mati. Dibangun setelah ide 1 live. Dampak sedang, usaha
kecil.

## Tidak direkomendasikan
- Ambien generate AI on-device (berat, boros baterai; sudah
  dicatat di Ide 15).
- Autoplay saat load (diblokir browser; MDN + kebijakan autoplay
  2026 — AudioContext suspended sampai gestur).
- Loop audio berlisensi di paket awal (beban unduh + lisensi;
  prosedural menghilangkan kebutuhan ini).
- Musik latar penuh sebagai langkah pertama (mengubah suasana +
  beban; ambien dulu, musik belakangan bila terbukti perlu).
